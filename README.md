# AFTERIMAGE · Физика души

Готовый статический HTML-лендинг на основе макета Figma

## Запуск

Нужен HTTP-сервер, поскольку 3D-модели загружаются как файлы GLB

Установленный Node.js: `node serve.cjs`, затем http://127.0.0.1:8844

## GitHub Pages

Загрузите содержимое этой папки в корень репозитория
В Settings → Pages выберите Deploy from a branch → main → / (root)
После публикации относительные пути работают и на адресе вида username.github.io/repository/
Никаких сборок, ключей API или внешних CDN не требуется

## Состав

- index.html — семантическая разметка и тексты
- styles.css — desktop и mobile
- app.js — мобильное меню
- assets/liquid.js — WebGL, живые деформации, пульсация солнца, вращение и инерция
- assets/models — четыре настоящие объёмные GLB-модели
- assets/vendor — локальная библиотека Three.js и загрузчик
- assets/images/hero-scene.png — исходная сцена, экспортированная из текущего макета Figma
- source — редактируемая геометрия и экспорт моделей

Формы вращаются перетаскиванием и стрелками клавиатуры, Home возвращает исходный ракурс
При системной настройке reduced motion автоматическое движение отключено
Внизу страницы есть переключатель движения
Вертикальный жест на телефоне сохраняет прокрутку, горизонтальный вращает форму

## Проверено

Макет в браузере на desktop и узком экране, меню, навигация, WebGL-модели, ручное вращение, переключатель движения
Тесты математической модели инерции: независимость от частоты кадров, затухание и ограничение скорости
